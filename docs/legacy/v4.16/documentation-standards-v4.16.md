# GravitationalWave Platform — 文档规范与术语表（v4.16）

> **用途**：本文档是 GW 平台所有技术文档的**唯一规范来源**。所有新文档和现有文档修改必须遵守本文档。

---

## 1. 标点与排版规范

### 1.1 代码块

**正确**：
````markdown
```yaml
interval: 10s
timeout: 5s
retries: 5
```
````

**错误**：
- `interval: 10s | timeout: 5s` — 禁止用管道符 `|` 分隔 YAML 字段。YAML 必须逐行书写。
- 代码块内缩进丢失 — 所有代码块必须有正确的缩进层级。

### 1.2 表格内代码与文字

**正确**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_workers` | `4` | 最大工作线程数 |

**错误**：
| 参数 | 默认值 | 说明 |
|------|--------|------|
| max_workers | 4 | 最大工作线程数 — 代码标识符不加反引号 |

**规则**：表格内的代码标识符、文件名、路径、命令必须用 `` ` `` 包裹。纯中文描述不加反引号。

### 1.3 Markdown 层级

- `#` 一级标题：仅用于文档标题（一个文件一个）
- `##` 二级标题：主要章节
- `###` 三级标题：子章节
- `####` 四级标题：细节项（非必要不用）
- 禁止跳级（如 `##` 后直接 `####`）

### 1.4 列表

- 无序列表统一用 `-`（不用 `*` 或 `+`）
- 有序列表用 `1.` `2.` `3.`
- 嵌套列表缩进 2 空格

## 2. 符号规范

### 2.1 全角 vs 半角

| 场景 | 正确 | 错误 |
|------|------|------|
| 数值 + 单位 | `768m` `900px` `10s` `5min` | `７６８ｍ` `９００px` `１０s` |
| 乘号 | `900×900` 或 `900x900` | `900×900px`（混用） |
| 中文括号 | 中文语境用全角（）：`端口（port）` | `端口(port)` |
| 英文括号 | 代码/英文语境用半角(): `get(id)` | `get（id）` |

### 2.2 版本号书写

**正确**：
- `v4.11 → v4.16`（旧→新，按时间顺序）
- `Spring Boot 2.3.7 → 3.4.1`
- 版本区间：`v4.12 – v4.16`（用 en-dash `–` 或箭头 `→`，旧版本在前）

**错误**：
- `v4.16 – v4.12`（新版本在前，逻辑倒置）
- `v4.12-v4.16`（用连字符代替区间符）

### 2.3 管道符 `|` 的正确用法

- **仅用于 Markdown 表格分隔**：`| 列1 | 列2 |`
- **禁止用于 YAML/代码片段内分隔字段**
- **禁止用于表示"或"**：应使用中文"或"或英文斜杠 `/`

## 3. 统一术语表

### 3.1 数据与存储

| 术语 | 定义 | 禁止混用 |
|------|------|---------|
| **ES** | Elasticsearch 7.17.28 | 不写 "ElasticSearch"、"ES 集群"（当前单节点） |
| **MongoDB** | MongoDB 6.0.26 | 不写 "Mongo"、"mongodb" |
| **索引** | ES 的 index（`alicptabnormal`） | 不写 "index_name"（代码标识符除外） |
| **集合** | MongoDB 的 collection（`comments`） | 不写 "collection 表"、"Mongo 表" |
| **文档** | ES/MongoDB 的单条记录 | 不写 "记录"、"条目" |

### 3.2 天文与坐标

| 术语 | 定义 | 统一写法 |
|------|------|---------|
| **天球坐标** | RA (Right Ascension) + Dec (Declination) | 统一中文："赤经 (RA)" / "赤纬 (Dec)" |
| **坐标字段** | ES 中的 geo-point 字段名 | `mapping_location`（代码中） / "坐标字段"（文档中） |
| **FOV** | Field of View，视场角 | 单位：角分 (arcmin) |
| **WCS** | World Coordinate System | 不写 "wcs"（小写，除代码外） |
| **子午线** | RA=0°/360° 分界线 | 统一 "RA 子午线"，不写 "经度线" |

### 3.3 查看器

| 术语 | 定义 | 统一写法 |
|------|------|---------|
| **Aladin** | Aladin Lite v3，CDS 天球查看器 | 统一 "Aladin"（首字母大写），不写 "aladin"、"Aladin Lite"（正式名称除外） |
| **Firefly** | IPAC Firefly，FITS 查看器 | 统一 "Firefly"，不写 "firefly"、"FireFly" |
| **双查看器** | Aladin + Firefly 共存 | "双查看器模式"，不写 "双视图" |
| **默认查看器** | 页面初始加载的查看器 | 当前：Error Analysis → Aladin；FITS Search → Firefly |

### 3.4 AI 模块

| 术语 | 定义 | 边界 |
|------|------|------|
| **AI Assistant** | 前端 AI 对话页面（`/assistant`） | 用户交互界面 |
| **DeepSeek API** | DeepSeek-V4 大语言模型 API | 后端 LLM 调用提供方 |
| **LLM Proxy** | Pipeline 的 `/pipeline/llm/chat` 代理端点 | 后端到 DeepSeek 的中转 |
| **MCP Server** | `gw-mcp-server`，MCP 协议服务器 | Claude Desktop / 自定义 AI 的工具接口 |
| **AI Models Hub** | 前端浮动按钮弹出的模型面板 | 展示模型状态和规划 |

**规则**：
- 前端功能 → "AI Assistant"
- 后端调用 → "DeepSeek API" 或 "LLM 调用"
- 工具协议 → "MCP Server"
- 模型面板 → "AI Models Hub"
- 禁止笼统称 "AI 模块"、"大模型"

### 3.5 版本相关

| 术语 | 格式 | 示例 |
|------|------|------|
| 平台版本 | `v<major>.<minor>` | `v4.16` |
| 组件版本 | `<name> <version>` | `Spring Boot 3.4.1`、`ES 7.17.28` |
| 版本区间 | `v<旧> → v<新>` 或 `v<旧> – v<新>` | `v4.11 → v4.16` |

## 4. 已知文档错误与修正

### 4.1 版本逻辑倒置

**错误**：多处出现 "v4.16-v4.12"（新在前，旧在后）
**修正**：统一为 "v4.12 → v4.16" 或 "v4.12 – v4.16"

### 4.2 重复条目

**错误**：审查条目中 "v4.7: 3-Agent 对抗式代码审查 R1" 出现两次
**修正**：保留一条，另一条改为 "v4.7: 3-Agent 审查 — 第二轮修复验证"

### 4.3 上下文断裂

**错误**："FITS 二进制完整性校验" 段落缺少前文铺垫
**修正**：前加 "为提高数据安全性，v4.16 新增了 FITS 二进制完整性校验功能："

### 4.4 内存格式

**错误**：`-Xmx768m` 与 `-Xmx768M` 混用
**统一**：`-Xmx768m`（小写 m 表示 MB）

### 4.5 尺寸格式

**错误**：`900×900px` 混用乘号和单位
**统一**：`900×900 px` 或直接 `900×900`（上下文明确为像素时省略 px）
