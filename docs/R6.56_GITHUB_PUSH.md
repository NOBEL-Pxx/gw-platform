```bash
# Push main branch (currently r6.52 — push as main for GitHub)
```

```bash

# Then on GitHub UI: Settings → Branches → Default branch → switch to r6.52
```

## Troubleshooting

- **`remote: Permission to NOBEL-Pxx/gw-platform denied`**: gh token lacks push scope. Regenerate token at https://github.com/settings/tokens with `repo` (full control).
- **`fatal: refusing to merge unrelated histories`**: Add `--allow-unrelated-histories` to first push.
- **`error: src refspec r6.52 does not match any`**: Branch renamed? `git branch -a` to list.

## Why not CI before push

Current zjlab deployment uses bastion ssh + cloudflared tunnel, not GitHub.
Until GitHub push + Actions are wired, vitest CI is local-only.

After GitHub push, R6.57+ can enable auto-deploy zjlab via `gh workflow run deploy.yml`.

## Deferral

R6.56 leaves this as PXX manual step because:
1. gh token (NOBEL-Pxx fine-grained) lacks `repo: create` scope
2. Repository creation is a one-way irreversible action (can't make private → public → private cycles easily, would lose stars/watchers)
3. PXX should explicitly approve visibility choice (public vs private)
