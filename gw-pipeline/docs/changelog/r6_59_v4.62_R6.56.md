## 1) vitest v2.1.9 → v3.2.7 (CVE fix, no vite-6 cascade)

**Critical CVE**: GHSA-5xrq-8626-4rwp (file read via UI server)

Decision: Upgrade to vitest 3.2.7 (CVE-fixed minimum), NOT vitest 5.0.0.

Why not 5.0.0:
- vitest 5 requires vite 6 (cascade to vite 6 + rollup 4 breaking)
- vitest 3.2.6+ fixes the critical CVE without vite dependency
- 34 tests pass unmodified in vitest 3.x

Alternative considered: vitest 5.0.0 (full rewrite path)
Risk-managed: 3.2.7 = minimum fix + no API change for our tests
