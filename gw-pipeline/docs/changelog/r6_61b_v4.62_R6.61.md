## 本次改动（MultiBandDataPanel.tsx + 重构）

### 1. 提取共享工厂 `buildImageUrl(e, size, ra, dec, contrastAdjust, quality)`
```ts
function buildImageUrl(
  e: OrderedEntry,
  size: number,                  // ← 唯一变化的参数
  ra?: number,
  dec?: number,
  contrastAdjust?: Record<string, number>,
  quality: 'standard' | 'high' = 'standard',
): string
```

**逻辑层次**：
- RGB + hipsColor + ra/dec → `/pipeline/merge-rgb` (q='high' + rgbChannels) else `hipsCutoutUrl`
- RGB 无 hipsColor → 替换 e.url 中的 `size=N` 参数
- Band + ra/dec + getHipsId → `hipsCutoutUrl`
- Band 无 HiPS → `/pipeline/thumbnail?size=N` 或 `img_path` fallback

### 2. `thumbUrl` 和 `largeImageUrl` 变成 thin wrappers
```ts
function thumbUrl(e, ra, dec, contrastAdjust, quality='standard'): string {
  const hipsBased =
    (e.kind === 'rgb' && !!e.hipsColor) ||
    (e.kind === 'band' && !!getHipsId(e.survey, e.item.band || ''))
  const size = hipsBased ? THUMB_HIPS_SIZE : THUMB  // 400 vs 100
  return buildImageUrl(e, size, ra, dec, contrastAdjust, quality)
}

function largeImageUrl(e, ra, dec, contrastAdjust, quality='standard'): string {
  const size = LARGE_SIZE_BY_SURVEY[e.survey] || LARGE_SIZE_DEFAULT
  const q = e.kind === 'rgb' && e.hipsColor ? getHipsQuality(e.hipsColor) : quality
  return buildImageUrl(e, size, ra, dec, contrastAdjust, q)
}
```

### 3. 关键常量
```ts
const THUMB = 100                  // FITS thumb fallback (R6.2 lean)
const THUMB_HIPS_SIZE = 400        // HiPS thumb (was hardcoded 400 in thumbUrl)
const LARGE_SIZE_BY_SURVEY = {     // R6.16 per-survey sweet spot
  '2MASS': 600, 'DSS2': 400, 'SDSS': 400, 'allWISE': 400,
  'LEGACY': 400, 'NVSS': 400, 'AliCPT-1': 150, 'Planck': 400,
}
const LARGE_SIZE_DEFAULT = 400
```

## 一致性铁律测试（THE CONSISTENCY INVARIANT）

```ts
describe('THE CONSISTENCY INVARIANT', () => {
  // 对每个 survey，验证 thumb(400) 和 large(LARGE_SIZE_BY_SURVEY) 的 URL
  // 仅在 width/height/fov 参数上不同。
  // width/height 是设计上的差异，fov 同步缩放（fov = 3 * size/400，
  // 同一片天区，更高像素密度）。
  const stripSize = (u: string) =>
    u.replace(/size=\d+/g, 'size=N')
     .replace(/width=\d+/g, 'width=N')
     .replace(/height=\d+/g, 'height=N')
     .replace(/fov=[0-9.]+/g, 'fov=N')
  expect(stripSize(tUrl)).toBe(stripSize(lUrl))
})
```

**覆盖 7 个 survey**:
- DSS2 / 2MASS / allWISE / NVSS (band HiPS)
- AliCPT-1 / Planck (band non-HiPS)
- 2MASS RGB HiPS high quality (merge-rgb path)

## 注意事项

- **buildImageUrl 已导出**（`export function buildImageUrl`），方便 vitest 独立测试。
- **`fov` 同步缩放**：`fov = max(0.01, 3 * size/400)` — by design（同一片天区，更高像素密度）。
  这是 urlDiffOnlyInSize 的**已知例外**，stripSize 函数已覆盖。
- **Hooks Rule 铁律保留**：thumbUrl/largeImageUrl 之前是 module-level 函数，无 hooks。
  buildImageUrl 也是纯函数，无 hooks。组件 hooks 不受影响。
