## 手动 squash (git subtree add --squash 失败)

`git subtree add --prefix=gw-backend gw-backend master --squash` 报错:

```
rejected refs/heads/master because shallow roots are not allowed to be updated
```

**原因**: gw-backend 是 shallow repo (只 5 commits from `ecc4e36`，无 common ancestor
with 主仓)，git subtree 不允许 shallow roots 更新。

`git fetch --unshallow` 也失败 (github.com 不可达)。

**方案**: 手动 extraction —
1. `mv gw-backend .trash/gw-backend-original-YYYYMMDD` (保留可恢复副本)
2. `rm .git-stash/gw-backend` 后重新解包 clean HEAD tree at `6066f4a`
3. `mv gw-backend/.git .trash/gw-backend-original-git-YYYYMMDD` (删嵌套 repo)
4. `git add gw-backend/` — git 不再拒绝 (submodule safety 已解除)
5. commit 为单一 squash merge commit
