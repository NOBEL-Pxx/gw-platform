## #1 Audit unified search — q / offset / match_field / highlight ✅

### 用户原话
> 「R6.52 #1: Audit 搜索高亮 (LIKE offset/match_field in search_alert_routing_audit)」

### 改动

**audit_v437_extensions.py**: `unified_search()` 增加 2 个参数：
- `q: str = None` — 全字段 substring 搜索 (Mongo `$regex` + `re.escape`，ReDoS-safe)
- `offset: int = None` — skip N entries (覆盖 page-based，for infinite-scroll)

返回新增字段：
- `match_field`: 第一个匹配的 string 字段名
- `highlight`: 该字段值，匹配子串用 `**...**` 包裹

**routes_v437.py**: `/pipeline/admin/audit/unified` 端点暴露 `q` + `offset` 为 Query 参数。

### 实现要点

1. **Mongo 端 `$or` 跨 11 string 字段**：
   ```python
   string_fields = ["session_id", "user_id", "action", "endpoint", "method",
                    "tool_name", "user_role", "source", "message",
                    "arguments_summary", "result_summary"]
   filt["$and"] = filt.get("$and", []) + [
       {"$or": [{f: {"$regex": q_pat, "$options": "i"}} for f in string_fields]}
   ]
   ```

2. **`re.escape(q_pat)`** — 阻止 regex 注入 + ReDoS。

3. **`_first_string_match(doc, q_lower)` helper**：
   - 跳过 `_id`, `_source`, `timestamp`, `match_field`, `highlight`
   - 第一个匹配的 string field → 返回 `(match_field, highlight)`
   - 字符串化所有值 (含 numeric 字段如 404)

4. **truncation (200-char window)**：
   - `start = max(0, idx - 60)`, `end_w = start + 200`
   - 在 raw window 上先 apply `**...**` markers，再 wrap `...` prefix/suffix
   - 避免 local_idx 与 prefix 字符的 offset mismatch bug

5. **offset 优先于 page**：
   ```python
   skip_n = offset if offset is not None else (page - 1) * page_size
   ```

### 测试覆盖 (7 cases)

| Case | Input | Expected |
|------|-------|----------|
| Short | `{'msg': 'NEEDLE here'}` | `'**NEEDLE** here'` |
| Long (truncation) | `'x'*500 + 'NEEDLE' + 'y'*500` | `'...xxx...**NEEDLE**yyy...'` len=210 |
| Near-start | `'NEEDLE' + 'x'*1000` | `'...**NEEDLE**xxx...'` len=207 |
| Near-end | `'x'*1000 + 'NEEDLE'` | `'...xxx**NEEDLE**'` len=73 |
| Full-value match | `{'a': 'apple'}` | `'**apple**'` |
| Numeric | `{'code': 404}` | `'**404**'` |
| Internal-skipped | `{'msg': 'needle_smith'}` with `_id/timestamp/highlight` containing 'NEEDLE' | `'msg'`, `'**needle**_smith'` |

### #3 HiPS cache TTL per-survey ✅

**位置**: `gw-pipeline/src/pipeline/routes_v450.py:403-422`

```python
# R6.52 #3: Per-survey TTL table. DSS2 static, 2MASS slow-changing,
# Gaia daily-updated. Values are seconds. Override via env HIPS_TTL_DSS2_S etc.
_HIPS_TTL_BY_SURVEY = {
    "DSS2": int(os.environ.get("HIPS_TTL_DSS2_S", str(7 * 86400))),     # 7 days
    "2MASS": int(os.environ.get("HIPS_TTL_2MASS_S", str(30 * 86400))),  # 30 days
    "Gaia": int(os.environ.get("HIPS_TTL_GAIA_S", str(86400))),         # 1 day
    "default": float(os.environ.get("HIPS_STALENESS_THRESHOLD_S", "1800")),  # 30 min fallback
}

def _detect_survey_type(cache_key: str) -> str:
    if not cache_key:
        return "default"
    k = cache_key.lower()
    for s in ("dss2", "2mass", "gaia"):
        if s in k:
            return s.upper() if s != "dss2" else "DSS2"
    return "default"
```

`/pipeline/hips-cache-staleness?survey=DSS2` 用 per-survey TTL。
